# 冻结标注 FreezeMark 使用说明

一个文件 `FreezeMark.exe`，免安装、不联网，双击运行后在托盘待命。

## 后台常驻与开机自启（v1.1）

- **开机自启默认开**：第一次运行就自动注册，之后每次开机/登录自动在托盘待命，不用手动打开。和 UseStats 同一套规则：托盘右键取消「开机自启动」的勾即可关，关过会记住、不会复活；把 exe 挪到别的文件夹后，下次运行会自动把自启路径刷新到新位置。
- **低占用**：待命时不轮询、没有定时器，进程阻塞在系统消息队列上等按键，任务管理器里应看到 CPU 0%；内存就是一个原生小进程的量。截图、画图的代码只有冻结那一刻才跑。
- 自启写在当前用户注册表 `HKCU\...\Run\FreezeMark`，不需要管理员权限；不想用了：先在托盘关掉自启，再退出程序删 exe 即可，无残留。

## 操作

| 操作 | 效果 |
|---|---|
| 同时按下 Enter + Backspace | 冻结当前屏幕（再次同按可解冻） |
| 左键按下拖动 | 按当前形状画标记，松手定稿 |
| 鼠标滚轮 | 调线条粗细 1–20 px（左下角会闪现当前值，浮窗右侧也显示） |
| 鼠标中键 | 切换到下一个线条颜色（按面板顺序红→橙→黄→绿→蓝→紫→黑→白循环；拖框途中按也会当场变色，且胶囊会立刻显回来让你看到新颜色） |
| 右键单击 | 退出冻结模式 |
| Esc | 退出冻结模式（备用） |
| 托盘双击 / 托盘右键菜单 | 冻结屏幕 / 退出程序 |

## 浮窗：纸面小岛（v1.3，学 sketchbook-ui + beUI）

冻结后，屏幕顶部中央是一颗**米白纸面胶囊**：墨黑手绘双线边（第二道线故意微微错位）、右下硬阴影，像从素描本上剪下来贴在屏幕上。上面只有两样东西：当前颜色圆点和「N px」（手写风字体）——没有线样预览，没有任何其他文字。冻结画面上也没有任何版本号之类的字样。

- **单击胶囊** → 它像 beUI 的灵动岛一样**形变展开**成纸面面板（0.3 秒带轻微回弹的舒展动画），展开过程中小球上的字会**先渐隐**、面板图标**随后渐显**，内容是交叉淡化换上的，不是硬切；控件全是图标、没有文字：撤回（弧形箭头）、清空（框中叉）、矩形 / 圆角矩形 / 圆形、实线 / 虚线（线样本身）、8 个颜色圆点；选中项是荧光黄高亮；面板左区只显示单行「N px」
- **点面板左侧的小胶囊** → 形变收回
- **在画面上按住左键画框时**，面板会先**自动收回成小球**，随即**渐隐消失**（约 0.1 秒），不挡你要标的位置；**松开左键**小球**渐显回来**（约 0.2 秒，保持收回状态，需要改设置时再点开）；按右键或 Esc 退出冻结也照常
- **拖动**胶囊/面板的空白处可移动位置；滚轮调粗细时数字实时变

> 小球/胶囊看不见的问题（v1.2/v1.3）：v1.4 做了两处针对性处理——①窗口区域设置后**当场读回校验**，若区域为空（窗口会完全不可见）立即撤掉区域改用矩形显示，日志 `toolbar: region readback type=` 就是结果；②**新版接管旧进程**：以前旧版还挂在后台时双击新版只会弹「已在运行」，实际跑的一直是旧版；v1.4 起新版会通知旧版退出、等不到就按进程名结束它再接管（日志 `takeover:` 系列）。另保留 1.2 秒 watchdog 自检（`watchdog:` 行）。若 v1.4 仍看不到胶囊，请把日志里 `region readback`、`watchdog`、`takeover` 三类行发回来，就能定死原因。

## 拖动中调粗细（v1.4）

按住左键拖着框不松手时，直接滚滚轮：预览框的线条粗细**当场变**（不用等移动鼠标），胶囊上的数字同步更新；松手定稿的就是最后看到的粗细。高分辨率滚轮的小格滚动也会累积计算，不会滚了没反应。

## 图标（v1.2）

程序有了自己的图标：玻璃蓝圆角方块＋珊瑚红标注框（四个白色手柄点）＋正中白色雪花——「冻结＋标注」。托盘、任务栏、exe 文件都用它，不再是 Windows 默认图标。若替换后托盘里还是旧样子，是 Windows 图标缓存，重启资源管理器或稍等即可。

## 注意

- 两个键要**几乎同时**按下：全局热键只能拦住后按下的那个键，先按下的那个可能会作用到下面的程序（比如在文档里先删了一个字）。练习两次就能掌握节奏，先轻按 Backspace 紧接着 Enter 最稳。
- 多显示器、缩放屏都支持（整块虚拟屏幕一起冻结）。
- 第一次运行若弹出 SmartScreen，点「更多信息 → 仍要运行」（本地编译、未签名，和 UseStats 一样的情况）。Defender 若误报，把所在文件夹加排除项。
- 程序不存任何截图和标记：退出冻结即全部丢弃。exe 旁只有一个诊断日志 `freezemark_debug.log`，出问题时把这个文件发回来即可。
- 彻底退出：托盘图标右键 →「退出程序」。卸载就是删掉 exe 和日志。

## 真机验证清单（按顺序，一项一项来）

1. 双击 exe：托盘出现图标，exe 旁生成 `freezemark_debug.log`，末尾有 `ready: waiting for Enter+Backspace`。
2. 同时按 Enter+Backspace：屏幕定住不动、顶部中央出现浮窗、左下角闪现提示；日志出现 `hook: Enter+Backspace combo` 和 `freeze: enter ok`。
3. 左键拖一个框松手：红框定稿；滚轮上下滚动：左下角提示的粗细数字变化，新画的框随之变粗/变细。
4. 浮窗逐个点：圆角矩形、圆形各画一个；虚线画一个；换个颜色画一个；点「撤回」应只删最后一个。
5. 右键单击：回到正常桌面；日志出现 `freeze: exited`。
6. 自启（v1.1 新增）：换上新版运行一次后，日志出现 `autostart: default-on applied` 和 `autostart: Run write ok`；重启电脑（或注销再登录），不手动打开，它应自己出现在托盘里且能按组合键冻结；任务管理器看一眼待命时 CPU 应为 0%。替换 exe 前记得先在托盘「退出程序」结束旧版，否则旧进程还在、自启注册的还是旧文件。
7. 纸面小岛＋图标（v1.3）：托盘图标应是新图标（日志有 `tray: app icon loaded from resource`）；冻结后顶部中央只有纸面胶囊、只显示「N px」，画面无任何文字提示，而且**停留不消失**（日志先有 `toolbar: after show visible=1`，约 1 秒后有 `watchdog: toolbar visible=1`）；单击胶囊有形变展开动画，面板图标能切换，点左侧小胶囊收起；滚轮时数字跟着变。
8. v1.4 两项：①直接双击下载的新版（不用先结束旧进程），它应自己接管（任务栏托盘图标闪一下、日志有 `takeover:` 行），随后冻结能看到胶囊——注意这次替换同名文件仍需先结束旧版，文件被占用时换不了；②按住左键拖出一个框别松手，滚滚轮，框线应立刻变粗/变细，日志出现 `wheel: lineWidth=… (during drag)`。
